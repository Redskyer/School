# 🌴 Mathe-Safari 🦁

Eine interaktive, kindgerechte Web-App zum Üben von Mathematik – optimiert für PC, Tablet und Smartphone.

## 🎯 Über das Projekt

Diese erste Version der Mathe-Safari wurde speziell für Schulkinder der **2. Klasse** entwickelt. Sie fokussiert sich darauf, den Zahlenraum bis 100 spielerisch und visuell ansprechend zu festigen. Die Kinder können verschiedene Aufgabenformate bearbeiten, wobei sie durch kleinschrittige Lösungswege unterstützt werden.

**Zukunftsausblick:**
Das Projekt befindet sich in der aktiven Weiterentwicklung. Geplant ist, die App künftig sukzessive auszubauen, um **weitere Jahrgangsstufen** (z. B. 1. bis 4. Klasse) abzudecken. Langfristig gibt es zudem erste Überlegungen, das interaktive Lernkonzept auf **weitere Schulfächer** auszuweiten.

## ✨ Features

* **Gezieltes Training:** Start- und Endwerte für den normalen Zahlenraum und reine Zehnerzahlen sind exakt einstellbar (z.B. Rechnen im Bereich von 50 bis 100).
* **Vielfältige Aufgabentypen:** 
  * Klassische Lückenaufgaben
  * Rechenschlangen (Länge individuell konfigurierbar)
  * Größenvergleiche (>, <, =).
* **Pädagogische Lösungswege:** Die Hilfe zeigt bei Bedarf den detaillierten Rechenweg an (inklusive "Nullertrick", Zehner- und Hunderterübergängen). 
* **Zwei-Stufen-Hilfe:** Kinder können wählen, ob sie nur den Rechenweg sehen wollen (Ergebnis bleibt verborgen) oder den Weg inklusive Lösung.
* **Fehler-Feedback:** Falsche Eingaben werden rot markiert, bleiben aber bearbeitbar, um Kinder zu einem zweiten Versuch zu motivieren.
